Rhyza provides a unified REST Admin API to manage your instance and its core resources.

## Admin API

The Admin API provides comprehensive capabilities to manage your Rhyza instance. Core capabilities include managing assets, wallet addresses, and peering relationships, as well as liquidity management through deposits and withdrawals. It also allows you to manage payment intents, quotes, and payments.
