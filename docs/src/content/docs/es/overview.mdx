Implementar y mantener la pila del [Interledger Protocol (ILP)](/es/concepts/interledger) puede resultar difícil y llevar mucho tiempo. Rhyza (<AudioIconButton src="./src/assets/rhyza.mp3" />) facilita a los [proveedores de servicios financieros](/resources/glossary#financial-service-provider-fsp) (FSP) la integración con la red de Interledger sin necesidad de desarrollar y mantener sus propias implementaciones.

:::tip[Try it out]
The [Local Playground](/testlocal) allows you to test Rhyza by running two mock FSPs that automatically peer with one another.
:::
