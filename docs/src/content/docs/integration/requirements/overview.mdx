## Required

Before deploying Rhyza to a production environment and joining the Interledger network, ensure you:

<table>
  <tr>
    <td>&#x2705;</td>
    <td>
      Are a licensed financial account servicing entity (ASE) in the
      jurisdictions you operate in
    </td>
  </tr>
  <tr>
    <td>&#x2705;</td>
    <td>Add at least one asset</td>
  </tr>
  <tr>
    <td>&#x2705;</td>
    <td>
      Implement a strategy for creating wallet addresses for your account
      holders
    </td>
  </tr>
  <tr>
    <td>&#x2705;</td>
    <td>
      Set up your webhook endpoint and understand how to handle each webhook
      event
    </td>
  </tr>
  <tr>
    <td>&#x2705;</td>
    <td>Secure your admin services from external access</td>
  </tr>
</table>

## Optional

<table>
  <tr>
    <td>&#x2705;</td>
    <td>
      **Integrate with an identity provider (IdP)**
      <p>
        If you plan to use the authorization server provided through Rhyza's
        Open Payments Auth Server, and/or support Open Payments outgoing
        payments, you **must** integrate with an IdP. An IdP is a system or
        service that stores and manages user identity information,
        authentication, and consent for an ASE's users.
      </p>
    </td>
  </tr>
  <tr>
    <td>&#x2705;</td>
    <td>
      **Add a peer**
      <p>
        A peer is another ASE that you connect with via Interledger who is
        likely running their own Rhyza instance. If you are using Rhyza solely
        for transfers between accounts on your own ledger, peers aren't
        required. Otherwise, you must [add at least one
        peer](/integration/requirements/peers) to enable Interledger payments on
        your accounts.
      </p>
    </td>
  </tr>
  <tr>
    <td>&#x2705;</td>
    <td>
      **Provide exchange rates**
      <p>
        If you plan to support cross-currency transactions, you must [provide
        exchange rates](/integration/requirements/exchange-rates) to Rhyza.
        Rhyza supports both pull and push models for obtaining rates, which are
        used to calculate the full cost of transferring value over the network.
      </p>
    </td>
  </tr>
</table>
